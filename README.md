# Filidas

Multilingual accommodation website developed for **Filidas Apartments** in Skiathos, Greece.

The platform is designed to showcase the property and its accommodation options to international visitors, with content available in three languages. It also includes an internal payment system that allows customers to securely complete electronic payments through an integrated payment gateway.

## Features

- Multilingual content in three languages
- Accommodation and property presentation
- Responsive design for desktop and mobile devices
- Internal electronic payment flow
- Payment gateway integration
- Dynamic content management

## Tech Stack

- **Backend:** Laravel / PHP
- **Database:** MySQL
- **Frontend:** Blade, JavaScript, HTML & CSS
- **Payments:** Payment Gateway Integration
